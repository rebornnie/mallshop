# MallShop 快速启动说明文档

## 一、前置条件

| 软件 | 版本 | 安装验证命令 |
|------|------|-------------|
| JDK | 17+ | `java -version` |
| Maven | 3.8+ | `mvn -version` |
| Docker | 20+ | `docker -v` |
| Docker Compose | 2.0+ | `docker-compose -v` |

## 二、快速启动步骤（9步）

### Step 1：启动中间件

```bash
cd mall
docker-compose up -d
```

等待约30秒后验证所有服务状态：

```bash
docker-compose ps
```

确认所有服务状态为 `Up`。逐一验证：

```bash
# MySQL — 返回 1 表示连接成功
mysql -h 127.0.0.1 -u root -proot -e "SELECT 1"

# Redis — 返回 PONG 表示连接成功
redis-cli ping

# Elasticsearch — 返回JSON集群信息表示成功
curl http://localhost:9200

# RabbitMQ — 返回HTML内容表示管理界面可用
curl -s -o /dev/null -w "%{http_code}" http://localhost:15672
```

### Step 2：初始化数据库

```bash
mysql -h 127.0.0.1 -u root -proot < sql/mall.sql
```

验证：

```bash
mysql -h 127.0.0.1 -u root -proot -e "USE mall; SHOW TABLES;"
# 应列出 19 张表
```

### Step 3：安装 ES IK 分词插件

```bash
docker exec -it mall-elasticsearch bash -c \
  "./bin/elasticsearch-plugin install https://github.com/infinilabs/analysis-ik/releases/download/v7.17.18/elasticsearch-analysis-ik-7.17.18.zip"
docker restart mall-elasticsearch
```

等待ES重启完成后验证：

```bash
curl http://localhost:9200/_cat/plugins
# 应看到 ik 行
```

### Step 4：创建 MinIO Bucket

1. 浏览器访问 http://localhost:9001
2. 输入用户名 `minioadmin`，密码 `minioadmin`，点击登录
3. 左侧菜单 **Buckets** → **Create Bucket**
4. 桶名称输入 `mall`，点击 **Create Bucket**
5. 点击 `mall` 桶 → **Access Rules** 标签 → **Add Rule**
6. 前缀输入 `*`，权限选择 `readwrite`，点击 **Save**

### Step 5：配置支付宝沙箱（可选）

```bash
export ALIPAY_APP_ID=你的沙箱APPID
export ALIPAY_MERCHANT_PRIVATE_KEY=你的应用私钥
export ALIPAY_PUBLIC_KEY=支付宝公钥
```

> 💡 如不配置，项目仍可正常启动运行，仅支付相关接口不可用。支付宝沙箱账号获取方式详见《人工配置文档》第四章。

### Step 6：编译项目

```bash
cd mall
mvn clean install -DskipTests
```

编译成功后输出 `BUILD SUCCESS`。

> ⏱ 首次编译需下载依赖，约需3-5分钟。

### Step 7：启动应用

**方式一：Maven 启动（开发推荐）**

```bash
cd mall-admin
mvn spring-boot:run
```

**方式二：JAR 包启动**

```bash
java -jar mall-admin/target/mall-admin-1.0.0-SNAPSHOT.jar
```

**方式三：后台运行**

```bash
nohup java -jar mall-admin/target/mall-admin-1.0.0-SNAPSHOT.jar > mall.log 2>&1 &
```

启动成功标志：控制台输出 `Started MallAdminApplication in X.XXX seconds`

### Step 8：验证启动

**检查Swagger文档：**

浏览器访问 http://localhost:8080/swagger-ui.html，应显示API文档页面。

**测试后台登录：**

```bash
curl -X POST http://localhost:8080/api/admin/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'
```

预期返回：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "token": "eyJhbGci...",
    "tokenHead": "Bearer "
  }
}
```

**测试前台注册（需先在数据库中添加测试数据或直接注册）：**

```bash
curl -X POST http://localhost:8080/api/ums/register \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800138000","password":"test1234","authCode":"123456"}'
```

**测试公开接口（无需Token）：**

```bash
# 商品分类列表
curl http://localhost:8080/api/pms/category/list

# 品牌列表
curl http://localhost:8080/api/pms/brand/list
```

### Step 9：导入商品数据到 ES

```bash
# 获取Token（从Step 8的返回值中复制token字段）
TOKEN="eyJhbGci...(替换为实际token)"

# 触发全量导入
curl -X POST http://localhost:8080/api/pms/es/importAll \
  -H "Authorization: Bearer $TOKEN"
```

> 💡 此步骤仅在有商品数据后需要执行。初始数据库为空时无需导入。

│   ├── service/               # 10个Service（后台全部业务逻辑）
│   └── dto/                   # 10个DTO（后台全部参数对象）
├── mall-portal/               # 前台商城API

│   ├── service/               # 6个Service（前台全部业务逻辑）
│   ├── dto/                   # 10个DTO（前台全部参数对象）
│   └── config/                # RabbitMQ死信队列 + 支付宝客户端配置
└── mall-search/               # 搜索服务
    └── ES实体/Repository/Service/Controller

## 六、常用操作

### 停止应用

```bash
# Maven方式：Ctrl+C

# JAR后台方式
ps -ef | grep mall-admin | grep -v grep | awk '{print $2}' | xargs kill
```

### 停止中间件

```bash
cd mall
docker-compose down

# 同时清除数据卷（⚠️ 会删除所有数据）
docker-compose down -v
```

### 查看应用日志

```bash
# Maven方式：直接在控制台查看

# JAR后台方式
tail -f mall.log
```

### 重新编译并启动

```bash
cd mall
mvn clean install -DskipTests
cd mall-admin
mvn spring-boot:run
```

## 七、常见问题排查

### Q1: 启动报 "Communications link failure"

**原因**：MySQL未启动或连接配置错误

**解决**：
```bash
docker-compose ps  # 检查MySQL状态
docker-compose up -d mysql  # 单独启动MySQL
# 检查application.yml中数据库地址/用户名/密码是否正确
```

### Q2: 启动报 "Unable to connect to Redis"

**原因**：Redis未启动

**解决**：
```bash
docker-compose up -d redis
redis-cli ping  # 应返回PONG
```

### Q3: 搜索接口返回空结果

**原因**：ES未安装IK插件或未导入商品数据

**解决**：
1. 检查IK插件：`curl http://localhost:9200/_cat/plugins`
2. 重新导入数据：见 Step 9

### Q4: 图片上传返回错误

**原因**：MinIO未启动或Bucket未创建

**解决**：
1. 检查MinIO状态：`curl http://localhost:9000/minio/health/live`
2. 确认 `mall` Bucket已创建并设置readwrite权限（见 Step 4）

### Q5: 支付功能不可用

**原因**：未配置支付宝沙箱密钥

**解决**：配置环境变量 ALIPAY_APP_ID / ALIPAY_MERCHANT_PRIVATE_KEY / ALIPAY_PUBLIC_KEY，详见《人工配置文档》第四章

### Q6: Maven编译报 "Could not find artifact"

**原因**：子模块POM的parent groupId不一致

**解决**：确认所有子模块POM的parent groupId为 `com.mallshop`，与父POM一致

### Q7: 启动报 "Port 8080 already in use"

**原因**：8080端口被其他程序占用

**解决**：
```bash
# 查找占用进程
lsof -i :8080
# 终止进程或修改application.yml中server.port
```

### Q8: RabbitMQ连接失败导致启动报错

**原因**：RabbitMQ启动较慢，应用启动时还未就绪

**解决**：
```bash
# 等待RabbitMQ完全启动后重新启动应用
docker-compose logs rabbitmq | grep "Server startup complete"
```
