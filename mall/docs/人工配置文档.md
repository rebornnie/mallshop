# MallShop 人工配置文档

## 一、环境要求

| 软件 | 版本 | 说明 |
|------|------|------|
| JDK | 17+ | Spring Boot 3.x 最低要求 |
| Maven | 3.8+ | 项目构建工具 |
| MySQL | 8.0+ | 主数据库 |
| Redis | 7.0+ | 缓存/Token存储/接口限流 |
| Elasticsearch | 7.17+ | 商品全文搜索（需安装IK中文分词插件） |
| RabbitMQ | 3.10+ | 消息队列（订单超时自动取消） |
| MinIO | latest | 对象存储（商品图片/头像上传） |
| Docker | 20+ | 推荐，用于快速启动中间件 |

## 二、中间件配置

### 2.1 Docker Compose 一键启动（推荐）

```bash
cd mall
docker-compose up -d
```

启动后各服务地址和默认账号：

| 服务 | 地址 | 默认账号 | 默认密码 |
|------|------|---------|---------|
| MySQL | localhost:3306 | root | root |
| Redis | localhost:6379 | 无 | 无 |
| Elasticsearch | localhost:9200 | 无 | 无 |
| RabbitMQ | localhost:5672 | guest | guest |
| RabbitMQ管理界面 | localhost:15672 | guest | guest |
| MinIO API | localhost:9000 | minioadmin | minioadmin |
| MinIO管理界面 | localhost:9001 | minioadmin | minioadmin |
| Kibana | localhost:5601 | 无 | 无 |

### 2.2 Elasticsearch IK 分词插件安装

IK分词插件是商品中文搜索的必要组件，ES容器启动后需手动安装：

```bash
# 进入 ES 容器
docker exec -it mall-elasticsearch bash

# 安装 IK 分词插件（版本必须与 ES 版本 7.17.18 一致）
./bin/elasticsearch-plugin install https://github.com/infinilabs/analysis-ik/releases/download/v7.17.18/elasticsearch-analysis-ik-7.17.18.zip

# 退出并重启容器使插件生效
exit
docker restart mall-elasticsearch
```

验证IK插件安装成功：

```bash
curl http://localhost:9200/_cat/plugins
# 应看到 ik 相关行
```

### 2.3 MinIO Bucket 创建

项目使用MinIO存储商品图片和用户头像，需手动创建Bucket：

1. 浏览器访问 http://localhost:9001 登录（minioadmin / minioadmin）
2. 左侧菜单点击 **Buckets** → **Create Bucket**
3. 输入桶名称 `mall`，点击 **Create Bucket**
4. 选中 `mall` 桶 → **Access Rules** 标签 → **Add Rule**
5. 前缀填 `*`，访问权限选 `readwrite`，点击 **Save**

> ⚠️ 如果不设置readwrite权限，图片上传接口将返回权限错误。

## 四、支付宝沙箱配置

### 4.1 获取沙箱账号

1. 访问 [支付宝开放平台沙箱](https://open.alipay.com/develop/sandbox/app)
2. 使用支付宝账号登录
3. 在沙箱应用页面获取以下信息：
   - **APPID** — 沙箱应用的AppID
   - **应用私钥（merchantPrivateKey）** — 使用密钥工具生成
   - **支付宝公钥（alipayPublicKey）** — 上传应用公钥后获取

> 密钥工具下载：https://opendocs.alipay.com/common/02kipk

### 4.2 配置方式

**方式一：环境变量（推荐，避免密钥泄露）**

```bash
export ALIPAY_APP_ID=你的沙箱APPID
export ALIPAY_MERCHANT_PRIVATE_KEY=你的应用私钥
export ALIPAY_PUBLIC_KEY=支付宝公钥
```

**方式二：修改 application.yml**

直接在 `mall-admin/src/main/resources/application.yml` 中填入：

```yaml
alipay:
  appId: 你的沙箱APPID
  merchantPrivateKey: 你的应用私钥
  alipayPublicKey: 支付宝公钥
```

> ⚠️ 应用私钥是敏感信息，请勿提交到版本控制系统。

### 4.3 回调地址配置

支付宝通过异步回调通知支付结果。本地开发时需将服务暴露到公网：

**使用 ngrok（推荐）：**

```bash
# 安装 ngrok
brew install ngrok

# 暴露本地8080端口
ngrok http 8080

# 设置回调地址为 ngrok 提供的公网URL
export ALIPAY_NOTIFY_URL=https://xxxx.ngrok.io/api/oms/pay/callback
```

**使用 cpolar：**

```bash
cpolar http 8080
export ALIPAY_NOTIFY_URL=https://xxxx.cpolar.top/api/oms/pay/callback
```

> 如不配置回调地址，支付功能仍可发起，但无法自动更新订单状态，需手动查询。

## 六、ES 索引初始化

项目首次启动后，MySQL中的商品数据不会自动同步到ES，需手动触发：

```bash
# 1. 先获取管理员Token
TOKEN=$(curl -s -X POST http://localhost:8080/api/admin/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}' | grep -o '"token":"[^"]*"' | cut -d'"' -f4)

# 2. 触发全量导入
curl -X POST http://localhost:8080/api/pms/es/importAll \
  -H "Authorization: Bearer $TOKEN"
```

也可通过 Swagger UI (http://localhost:8080/swagger-ui.html) 手动调用。

> 后续新增/修改商品时，需重新执行导入操作同步数据到ES。生产环境建议通过消息队列实现增量同步。

## 七、生产环境注意事项

1. **修改所有默认密码**：MySQL、Redis、RabbitMQ、MinIO、JWT密钥
2. **开启Redis密码认证**：设置 spring.data.redis.password
3. **HTTPS部署**：通过Nginx反向代理配置SSL证书
4. **JWT密钥更换**：使用至少256位的高强度随机密钥
5. **数据库连接池**：根据实际并发量调整 druid 连接池参数
6. **ES堆内存**：生产环境建议 ES_JAVA_OPTS 设置 -Xms2g -Xmx2g
7. **RabbitMQ持久化**：确保消息队列的持久化和确认机制正确配置
